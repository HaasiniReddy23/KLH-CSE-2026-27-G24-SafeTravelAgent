# Data directory

Place only public, licensed, or otherwise authorized travel documents and curated test data here.

Suggested categories:
- Travel and accommodation policies
- Cancellation and refund policy examples
- Destination information
- Synthetic/mock booking records
- Prompt-injection red-team test cases

For each source, record its origin, license/permission, retrieval date, and any preprocessing performed.

Do not store API keys, passwords, payment details, real customer records, or confidential documents in this directory. Large datasets may be kept outside Git and referenced here with reproducible download instructions and checksums.
